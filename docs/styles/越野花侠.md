# 越野花侠 · 作品文风卡

> 锚点：与《越野滑雪》同源，叠加“花侠”式的侠气与艳色，不复刻台词，仅取神。

## 锚点（3-5）

1. **雪与花的对撞**：冷冽雪原上的一点艳色（衣角、花、唇），冷与暖在同一帧里。
2. **侠的克制**：出手与退让都点到为止，情意藏在“护你一段路”的姿态里。
3. **风物的仪式感**：启程、并肩、递物、回望——动作本身即表白。
4. **低哑的承诺**：不说永远，只说“这程我陪你滑完”，以行动兑现。
5. **身体的诚实**：冷风割面、指尖相触的热，让暧昧有体温。

## 落点提示

- 侠气不靠台词堆，靠“递、护、挡、让”四类动作的克制分寸。
- 艳色宜点到为止，一处足矣。
