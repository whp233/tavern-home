# 越野滑雪 · 作品文风卡

> 锚点：供 plotOutline → 小纸条氛围注入，不直接照搬原文，仅神似。

## 锚点（3-5）

1. **雪原的呼吸感**：冷空气、雪粒摩擦、呼吸白雾与心跳同频，环境先于台词抵达。
2. **克制而灼热的距离**：少言、眼神与体感先行，情感在肩并肩的滑行与短暂停靠中递增。
3. **身体的真实**：汗、冷、酸痛与暖意交替，触感与重量让暧昧落地，不悬空。
4. **低语与留白**：对话短、尾音轻，留白让雪场的风声把未说完的话补完。
5. **同行而非追逐**：两人并线、偶尔落后又追上，胜负让位于“一起抵达”。

## 落点提示

- 滑雪场景中，让雪、风、光、体感先出现，再让人说话。
- 节奏：滑行-停靠-对视-再滑行的呼吸循环。
