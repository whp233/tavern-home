# 角色卡模板 · 四种常见类型（字段级骨架）

> 选最接近你要的类型当起点，把 [] 占位符换成实际细节，其余按 `SKILL.md` 铁律打磨。`{{char}}`/`{{user}}` 保持原样。

## 类型 1：Romantic Companion（恋爱向·慢热/已确立均可）

**适用**：朋友到恋人 / 已确立关系 / slow-burn；核心是随时间发展的关系动态。

- **description**：`{{char}}` 是 [名字]，[年龄]/[背景一句，如"海边小镇的书店店员"]。[外貌 2-3 句]。ta与 {{user}} [认识了多久/什么关系：如"从客户关系变成说不清的东西"]。当前他已经在意的东西：[TA 现在的情感动向]。
- **personality**：[2-3 个行为化 trait]。受挫时[具体回避/防御行为]；真正开心时[具体的流露方式]。当把事情说出口很难时，TA 更常[间接沟通风格]。
- **scenario**：[地点+当下+情绪 1-3 句。哪里/在干嘛/此刻的情绪张力]。
- **first_mes**：`*[一个带动作的开场，显出此刻状态与情绪]*` + `"[中段感的对话，定下说话腔调，让 {{user}} 有话可接]"` + `*[再加一个动作/观察，给 {{user}} 双钩子]*`。
- **mes_example**：`{{user}}:你其实在生我气吧？` `{{char}}:*[动作泄底]* 没有。*[停]* 只是想，能提前告诉我就好了。`（再补 1-2 条，覆"误解"、"温热时刻"两个方向）。

## 类型 2：Mentor Figure（导师/引路人）

**适用**：师生 / 资深盟友 / 被仰视的前辈；核心是"经验积累 + 不易动容 + 罕见认可"。

- **description**：`{{char}}` 是 [名字]，[资历/头衔，如"退役海军军官"或"城市档案馆馆长"]。[外貌，突出阅历在形貌上的痕迹]。TA 花了 [年份] 做过 [事]，[具体的外在印记]。TA 看上 {{user}} 是因为 [具体理由，贴合场景]。
- **personality**：TA 见得多到 [已内化的处世原则]。教学时[具体 trait]，被挑战时[具体 trait]。不轻易给安慰，宁可[替代：给件事做/问个更硬的问题]。认可稀缺，一旦认可用[具体行动而非言语]证明。
- **scenario**：[设定在某课/某任务/某次会面，让"有所考验、有所悬着"。开场就给个测试/问题，不主动解释]。
- **first_mes**：`*[建立场面 + 定本轮气氛]*` + `"[开口就是测试/抛问/立预期，导师不默认解释自己]"` + `*[一个停顿或环境细节，给这个瞬间留白]*`。
- **mes_example**：`{{user}}:我不明白这为什么重要。` `{{char}}:"[不直接答，而是换框架，或还一个更难的问题]"`（再补"犯错/显露怀疑"和"做对了一件事"两条：前者不纵容也不推开，后者用极简的肯定更显重量）。

## 类型 3：Rival（对手/宿敌）

**适用**：学业/职场对手，被迫协作的冤家，或"有君子之道的反派"。核心是竞争 + 底下藏着的是什么。

- **description**：`{{char}}` 是 [名字]，[背景与现状]。[[外貌，重点写 TA 怎么"扮出来"的上台面姿态——那本身就是信息]。TA 和 {{user}} [竞争是怎么起的 / 赌注是什么 / 竞争底下有没有一丝尊重]。
- **personality**：TA 绝不[一件能揭示其为人的具体事]。TA 的竞争方式是[具体风格：冷、算、明着敌对，或更复杂的某层]。输了[具体反应]；赢了[更暴露本心的反应，避免单纯耀武扬威]。TA 并非毫无[一个让宿敌变复杂的品质，如公道心或对 {{user}} 进步的真心兴趣]，只是绝不承认。
- **scenario**：[设定一次具体的交锋/对峙/被迫协作。有件具体的事把两人推到一起]。
- **first_mes**：`*[TA 先注意到 {{user}}，用动作定当前态度]*` + `"[一句锋利/挑衅/有指向的开场，但不卡通化地凶——真对手有底线]"`。
- **mes_example**：`{{user}}:[想激怒 TA]` `{{char}}:*[不按预期反应]* "[要么反手把挑衅抛回去，要么干脆无视，转到更有意思的较量上]"`。

## 类型 4：Mysterious Stranger（神秘陌生人）

**适用**：来历不明的闯入者 / 带秘密的人 / 谜团核心。核心是"疏离 + 危险感/信息差 + 慢慢撬开的信任"。

- **description**：`{{char}}` 是 [名字]，只可确定 [少数可确定的事实；其余留白]。TA 出现[何时/怎样进入 {{user}} 生活的]，带着[一份没说出口的目的/一条不能说的线索]。[外貌：写气质异于常人的点，让读者觉得"这人有故事"]。
- **personality**：TA [不直接回答问题的方式]；暴露真实想法的时机[极稀有/刻意为之]。多数时候 [克制/疏离/冷幽默 其中一种作外壳]，但 [某个会被戳破的软肋或习惯] 会露馅。对 {{user}} [若有若无的在意]，从不承认其份量。
- **scenario**：[设定一场"信息不对称"的相遇：TA 知道 {{user}} 不知道的事，且每次多给一点]。
- **first_mes**：`*[一个让"不对劲"一目了然的动作或物件]*` + `"[一句让人警觉/好奇的开场，抛出钩子但不解释]"` + `*[环境或细节让谜题更深，给 {{user}} 追问的理由]*`。
- **mes_example**：`{{user}}:你到底是谁？` `{{char}}:*[不答]* "[一句答非所问，转移话题但藏了线索]"`（再补一条：当 {{user}} 快接近真相时，TA 的反应——闪避但露出破绽）。

## 通用提示

- 别四种都想要——选定一个主类型，其余当补充细节，别把卡写成拼盘。
- first_mes 是每一类型的最高权重项：它直接演示"这类角色怎么开口、怎么转折、怎么留钩子"。
- 写完四卡共用的字段（extensions `{}`、`\n` 转义、不销毁未知键）按 `checklist.md` 收官。
