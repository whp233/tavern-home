# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

**Root (Cloudflare Workers + D1, Node ≥18.18, ESM):**
- `npm run dev` — `wrangler dev` (default 8787). Daily via `run.bat`: `npx wrangler dev --port 8799 --ip 0.0.0.0` + `frontend: npx next dev -p 3001 -H 0.0.0.0`
- `npm run typecheck` — `tsc --noEmit` (covers `src/` + `examples/`)
- `npm test` — `node --test tests/*.test.ts` (no framework). Single: `node --test tests/<name>.test.ts`
- `npm run build` — `node scripts/run-wrangler.mjs deploy --dry-run --outdir dist` (wraps wrangler with `.tmp-wrangler-config` + isolated `XDG_CONFIG_HOME`)
- `npm run release:check` — `typecheck && test && build && node scripts/release-hygiene.mjs`; CI (`.github/workflows/ci.yml`, Node 24, push/PR→main) runs `npm ci` + backend typecheck + `npm test` + frontend `tsc --noEmit`
- `npm run db:init:local` — `wrangler d1 execute tavern-home --local --file examples/cloudflare/schema/init.sql` (empty DB only); `npm run db:migrate:local` — apply `examples/cloudflare/schema/migrations/`. `run.bat` only runs `init` once (guarded by `.local-db-initialized`), migrations never auto-apply

**Frontend (`frontend/`, Next 16 App Router, must use webpack):**
- `cd frontend && npm run dev` / `npm run build` (`next build --webpack`) / `npm run lint` / `npx tsc --noEmit`

## Architecture

**Fork of `TricksterFlare/tavern-study`, standalone `tavern-home` (MIT).** `README.md` + `docs/data-model.md` are canonical; `AGENTS.md` holds non-obvious traps.

- **Backend entry** `examples/cloudflare/index.ts` — every writer-desk API under `/{AUTH_TOKEN}/api/oc/...` (missing token → 401). MCP + published-reading use Bearer `OWNER_TOKEN`/`COMPANION_TOKEN` instead. Pure logic lives in `src/core/` + `src/tools/` + `src/chat/desk.ts` + `src/adapters/streamModelBackends.ts`; D1 adapters `examples/cloudflare/adapters/d1*.ts` are reference dialect only. Contract is `StorageAdapter`/`DeskStorage` in `src/core/storage.ts` + types in `src/core/types.ts` — D1 column names are not the contract.

- **Frontend** entirely in `frontend/app/study/`: `page.tsx` (room router) + `TypingDesk.tsx` (desk + provider switch + `splitInlineThinking`/`FloorReportView`), `ChaptersStudio.tsx`, `ReadingCorner.tsx`, `DeskDrawers.tsx`, `LoreWindow.tsx`, `TokenUsagePanel.tsx`, etc. New rooms need an entry in `page.tsx`.

- **Prompt assembly** `src/chat/deskAssemble.ts` is the single D1/Vectorize touchpoint — `assembleDesk()` builds `system[]` (cacheable prefix) + `tail` (single user message) from recipe queue (`desk_blocks` + `overrides`), lore/char triggers (`loreTrigger.ts`), `deskMemory`, `recent/past/timeline/floors`, `stateBoard`, `COMPACT_INSTRUCTION`. Budget `STREAM_BUDGET=2800`, character cards merged to single `charCard`. `deskDryrun` exposes the same assembly without calling the model.

- **Generation chains share provider routing** — desk chat / `deskTimeline.ts` fold / `refreshDeskBoard` all go through `DESK_PROVIDER_DEFS` in `src/adapters/streamModelBackends.ts` (prefix `OPENAI_*`/`ANTHROPIC_*`/`DEEPSEEK_*`/`SILICONFLOW_*`, `safeEndpoint`/`openAiEndpoint` validation, `isPlaceholderKey` filtering). `deskProviderConfigured`/`resolveDeskProvider`/`listProviders` are the only "configured?" checks. Frontend persists `localStorage.oc_desk_provider`; `GET /api/oc/desk/providers` lists configured vendors. `COMPANION_COMMENT_WRITE` (`wrangler.toml` var, `"false"`=read-only) gates companion comment writes.

- **Schema** `examples/cloudflare/schema/init.sql` must be byte-identical to concatenation of `examples/cloudflare/schema/migrations/*.sql` sorted by name (enforced by `tests/schemaContract.test.ts`, 30s timeout, creates two real D1 instances). Change init → add matching migration; never edit init alone. `migrations_dir` set in `wrangler.toml`. D1 conventions: booleans `INTEGER CHECK(0/1)`, JSON `TEXT`, ISO timestamps.

## Config

- **Root `.dev.vars` (gitignored, generated by `run.bat`):** `AUTH_TOKEN` (path token) / `OWNER_TOKEN` / `COMPANION_TOKEN` + vendor keys `<PREFIX>_API_KEY/_BASE_URL/_MODEL`. `frontend/.env.local` = `NEXT_PUBLIC_WORKER_URL=http://localhost:8799` + `NEXT_PUBLIC_AUTH_TOKEN` (inlined at build — rebuild frontend after change). `[vectorize]`/`[ai]` bindings are intentionally commented out in `wrangler.toml` — enabling them requires `CLOUDFLARE_API_TOKEN` and breaks local `wrangler dev`; Vectorize degrades gracefully (`StudyService` capability `'disabled'`).

- **Factory reset:** delete `.wrangler/` + `.dev.vars` + `frontend/.env.local` + `.local-db-initialized` + `.tmp-*` + `dist/`.

## Gotchas

- `run.bat` must stay pure ASCII, no BOM, no Chinese — `cmd` parses as GBK; uses `!AUTH_TOKEN!` delayed expansion inside blocks.
- System `HTTP_PROXY`/`HTTPS_PROXY=http://127.0.0.1:10809` breaks `npm install` and model calls → clear both envs and force registry: `set HTTP_PROXY=& set HTTPS_PROXY=& npm install --registry=https://registry.npmjs.org`.
- `scripts/release-hygiene.mjs` fails on committed `.env`/`.pem`/tokens (`sk-ant-`, `gh*`); add legitimate hits to allowlist.
- Tests use `node:test` + `allowImportingTsExtensions: true`, isolation via `wrangler.test.toml` + `--persist-to .tmp-wrangler-*` + `XDG_CONFIG_HOME=.tmp-wrangler-config`; `schemaContract` needs 60s.
- Frontend UI is Chinese — keep new UI in Chinese. `CRLF` warnings on `git add` on Windows are expected.
